# v0.0.6

## Fixes

- `woodglue.config`: `NamespaceEntry.entries` now holds raw dicts instead of
  `NsNodeConfig`, so fragment fields (`type`, `init`, `configs`) survive Pydantic
  deserialization and inline fragment configs load correctly

## Changed

- `woodglue.apps.system_api` simplified to use the reworked lythonic `Method`
  interface, dropping the local pyright workarounds

## Documentation

- README and docs site revamp: trimmed README, reworked `docs/index.md`, removed
  the stale `docs/MillFarm.md`
- Added GitHub Pages deploy badge and link to README
- Added v0.0.5 release notes to mkdocs nav

## Dependencies

- lythonic upgraded 0.0.17 -> 0.0.22
